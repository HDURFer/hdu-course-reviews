## 阅读说明

本项目记录个人在**杭州电子科技大学**的课程学习体验，以电子信息相关课程为主，供学习、复习与选课参考，并持续补充。

> **个人经验，仅供参考。** 评价具有主观性，仅对应本人修读时的课程安排、授课与考核情况。不同年级、专业、教师和学年的要求可能不同，请以当前教学安排为准。

- **怎么读：**先看下方课程类型速查表；也可以直接展开某个学期，一次阅读该学期全部课程评价，无需逐门跳转。
- **评价口径：**“学习难度”“考核难度”“时间投入”分别描述，不用一个分数概括整门课；未确认的信息明确标注。
- **交流原则：**围绕课程内容、学习方法与亲身体验展开，尊重教师与同学。
- **资料使用：**笔记及参考链接仅供个人学习，PPT、PDF 等课程资料未经权利人许可请勿转载、转发、二次上传或商用。

### 信号与电路系统基础

**难度：★★★★☆（4/5）**

作为第一门专业课，卷积、傅里叶变换、拉普拉斯变换等内容难度较高。这类内容也是很多学校考研专业课的重要部分，建议认真学习。

课堂练习和习题较多，考试题目的计算量也很大。按个人体验，这门课比较容易挂科，需要重视平时学习与练习。

### 体育—足球（男）

**难度：★★★☆☆（3/5）｜趣味性：★★★★☆（4/5）**

- **课堂安排：**有签到，一般每节课会组织分成两队踢球。
- **当时期末考核：**开大脚、绕杆射门、颠球，三选一。
- **个人体验：**对于初学者难度较大，没有足球基础的话，分数可能会比较低。

### 托福英语 1

**个人评价：夯。**

老师人很好，上课也有趣。本人修读时不签到。

### 大学物理 1（H）

**个人评价：夯。**

老师人好，上课有趣。

### 法律与中国社会问题

**难度：☆☆☆☆☆（0/5）**

- **课堂要求：**有签到，平时分需要通过课堂回答问题争取。
- **当时期末考核：**手写论文。
- **个人印象：**老师很帅。

### 大学物理实验 A1（H）

**个人体验：牢完了。**

暂未补充具体实验内容、考核方式及体验原因，不据此推断课程难度或评分。

### 欧美流行音乐

**难度：★★☆☆☆（2/5）**

会介绍一些有趣的歌曲分类，上课会听歌。当时期末考试需要听辨歌曲属于什么类型，有一定难度。

### 信号与电路系统实验

**暂不评价。**

本人实验课相对薄弱，而且实验课基本为必修，因此不对这门课作评价。

### 电子设计基础创新实践

适合想参加电子设计竞赛的同学，但需要投入课下时间自主学习。

就个人体验而言，电赛比数学建模竞赛难很多。如果主要想尝试竞赛，个人更建议考虑数学建模；具体选择仍应结合自己的兴趣与基础。

> **以上均为本人修读时的个人体验。** 签到、考核项目、评分及课程安排可能随教师和学年变化，请以当前教学要求为准。

### 大二上 · 学期概览

本学期未提供星级评分，以下保留个人体验与定性描述。“夯”为个人主观评价。

| 课程 | 学习与投入特点 | 一句话体验 |
| :--- | :--- | :--- |
| 模拟电路与系统 | 难度较高，翻转课堂耗时很多 | 老师夯，想拿高分要重视课前预习 |
| 数字系统与处理器 | 内容极多、课时紧、节奏快 | 数电与 Verilog HDL 融合，拿高分不容易 |
| 中国礼仪文化 | 暂未补充 | 夯 |
| 复变函数 | 暂未补充 | 个人理解为“高数的频域版本”，夯 |
| 排球 | 初学者有一定难度 | 找好搭子，向有基础的同学学习 |
| 概率论与数理统计 | 作业较多 | 按个人体验，跟着老师的节奏学，通过问题不大 |

### 模拟电路与系统

**老师：夯。学习难度较高，时间投入很大。**

采用小班教学与翻转课堂。翻转课堂**非常、非常、非常花时间**，课堂上有很多测试和回答问题的环节。

按本人修读时的体验，期末考试没有课堂习题难。想拿高分，建议课前充分预习；如果正常跟上翻转课堂的学习要求，基本不用太担心挂科。

### 数字系统与处理器

这是一门融合数字电路与 **Verilog HDL** 的课程。课时紧张、讲得很快，内容极多。

本人修读时，期末既要画数字电路相关的图，也要写代码。总体感觉拿高分不容易，需要同时跟上数电知识与代码练习。

### 中国礼仪文化

**个人评价：夯。**

暂未补充课堂安排、考核方式及具体体验。

### 复变函数

**个人评价：夯。**

个人用“高数的频域版本”来形容学习感受。这是便于表达体验的类比，并非对课程内容的严格定义。

### 排球

对于初学者有一定难度，建议找好搭子。如果能和有基础的同学搭档、一起练习，会更有帮助——个人建议是“直接抱大腿”。

### 概率论与数理统计

作业比较多。不过，按个人体验，跟着老师的节奏完成学习与练习，基本不用太担心挂科。

> **以上均为本人修读时的个人体验，不构成通过或高分保证。** 教学模式、考试内容及评分要求可能随教师和学年变化，请以当前教学要求为准。

### 电磁场与电磁波

**一句话评价：课程内容多、推导多，但根据几年前的个人经验，考试以概念理解和部分基础计算为主。**

| 授课教师与具体学年 | 暂未补充 |

#### 课程内容与学习体验

电磁场与电磁波内容较多、难度较高，涉及大量公式推导。建议理解公式背后的物理意义，并注意区分不同介质、边界条件及传播情形。

#### 复习参考

根据几年前的个人考试经验，除计算题外，也要重视基本概念，建议了解：

- 趋肤效应。
- TEM、TE、TM 波的含义与区别。
- 麦克斯韦各方程的物理意义。
- 天线的基本参数。
- 波导、驻波和行驻波等概念。
