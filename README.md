## 阅读说明

本项目记录个人在**杭州电子科技大学**的课程学习体验，以电子信息相关课程为主，供学习、复习与选课参考，并持续补充。

> **个人经验，仅供参考。** 评价具有主观性，仅对应本人修读时的课程安排、授课与考核情况。不同年级、专业、教师和学年的要求可能不同，请以当前教学安排为准。

- **怎么读：**先看下方课程类型速查表；也可以直接展开某个学期，一次阅读该学期全部课程评价，无需逐门跳转。
- **评价口径：**“学习难度”“考核难度”“时间投入”分别描述，不用一个分数概括整门课；未确认的信息明确标注。
- **交流原则：**围绕课程内容、学习方法与亲身体验展开，尊重教师与同学。
- **资料使用：**笔记及参考链接仅供个人学习，PPT、PDF 等课程资料未经权利人许可请勿转载、转发、二次上传或商用。

**一句话评价：课程内容多、推导多，但根据几年前的个人经验，考试以概念理解和部分基础计算为主。**

| 授课教师与具体学年 | 暂未补充 |
| 作业、实验与考核占比 | 暂未补充 |

#### 课程内容与学习体验

电磁场与电磁波内容较多、难度较高，涉及大量公式推导。建议理解公式背后的物理意义，并注意区分不同介质、边界条件及传播情形。

#### 复习参考

根据几年前的个人考试经验，除计算题外，也要重视基本概念，建议了解：

- 趋肤效应。
- TEM、TE、TM 波的含义与区别。
- 麦克斯韦各方程的物理意义。
- 天线的基本参数。
- 波导、驻波和行驻波等概念。

新增课程时，将下方结构放入对应学期的折叠区块，并同步补充顶部的课程类型速查表。无需为每门课单独创建页面。

<details>
<summary><strong>展开查看：一门课程的评价结构</strong></summary>

### 课程名称

**一句话评价：**用一两句话说明最主要的学习体验。

| 信息 | 记录内容 |
| :--- | :--- |
| 修读时间 | 学年、学期 |
| 专业与课程类型 | 专业；专业基础／专业核心／实验实践等 |
| 授课教师 | 可选 |
| 学习难度 | 较低／中等／较高，并说明原因 |
| 考核难度 | 单独描述当年的实际体验 |
| 时间投入 | 作业、实验、报告和复习所需投入 |
| 考核方式 | 仅记录已确认的当年要求 |
| 评价时间 | 这篇评价的撰写或更新时间 |

#### 学什么

主要内容、知识结构，以及需要的先修基础。

#### 学习体验与难点

#### 作业、实验与考核

#### 学习与复习建议

具体学习顺序、重点概念、练习方法及时间安排。

#### 参考资料

> 本评价仅反映本人修读时的情况，请以当前教学要求为准。
